## 先说结论：SuperGrok 的溢价买的是什么

和 $20 档的 ChatGPT Plus、Claude Pro 相比，SuperGrok 的优势不在模型本身有多聪明。Grok 4.6 在 Artificial Analysis 智能指数上得 61 分，与 GPT-5.6 Sol 持平，Claude Opus 5 是 63 分，都在第一梯队，没有谁碾压谁。真正拉开差距的是三样别人没有的东西：

**X 平台实时数据。** Grok 原生读取 X 的内容流，做热点追踪、舆情观察、突发新闻梳理时，它看的是“现在”，而不是绕道搜索引擎拿二手信息。这是 Grok 最难被替代的能力。

**图像和视频在同一个界面里。** $30 档包含 AI 图像生成和最长 30 秒的 720p 视频，不用在几个工具之间来回跳。

**终端编码 agent。** Grok Build 是一个完整的命令行编码工具，$30 档就包含。网上不少资料把它标成 $299 或者说只有最贵档才有，这与 xAI 自己的公告对不上。

还有第四点，一半是卖点一半是风险：Grok 的内容限制明显比 ChatGPT 和 Claude 宽松，边界话题更容易得到正面回答。宽松是双刃剑，ADL 和 Common Sense Media 在 2026 年的评估中把它列为在极端内容处理上表现最差的主要模型。这一点能否接受，需要你自己权衡。

## $30 档的真实能力清单

官方套餐页上，$30 这档的清单是：比免费版长 5 倍的对话、更高的 Expert 模式额度、AI 图像、30 秒以内的 720p 视频、更长的语音对话、更快的回复速度，外加 Grok Bot 和 Grok Build 编码命令行。

Grok Build 值得单独说。它不是“会写代码的聊天窗口”，而是跑在终端里的编码 agent：读取项目里的 AGENTS.md，规划任务，按 diff 逐条审查再应用，支持 MCP 服务，能在 git worktree 里并行开子代理，还留了 headless 模式接脚本和 CI。$20 的 ChatGPT Plus 和 Claude Pro 属于聊天优先的订阅，编码能力有用量限制；终端优先的编码 agent 出现在 $30 价位，同价位的 $20 订阅里没有这个配置。对写代码的人来说，这一个功能就撑起了大半个订阅费。

日常使用还有几个实用细节：界面里有 auto、fast、expert 几种模式，默认 auto 自动分配，复杂问题切 expert 强制深度思考；自动化面板能设周期任务，connectors 可以接 Gmail、Google Drive、日历；自定义指令能让它长期记住你的背景和回答偏好。

$30 档没有的：1080p 视频（Plus）、高峰期优先（Plus 及以上）、最大用量池（Heavy）。

## 周限额怎么算：2026 年最大的变化

2026 年 6 月起，xAI 把原来各功能分开的每日限额，换成了一个共享的每周用量池。聊天、图像、视频、语音、Build，所有功能从同一个池子里扣。官方把它包装成灵活性，确实灵活，但池子不算大。

xAI 没有公布池子的具体大小，所以任何“每周 X 条”的精确数字都不是官方口径。社区实测出来的消耗比例大致是：一条 10 秒的 720p 视频约占 2%，480p 约 0.5%–1%，五条左右的短对话占 1%–2%。粗算下来，一整周大约够 50 条高清视频，或者五六个小时的普通对话，前提是这周你只干这一件事。

有三个细节会让池子消耗得比账面更快：

1. **被拦截的生成照样扣量。** 提示词触发内容审核、文件没拿到，那 2% 也已经扣了。有用户反馈连续触发二十次审核拦截后账号被锁，一张图都没拿到。
2. **升分辨率要重新扣量。** 把 480p 升到 720p 会从池子里再扣一次，不能复用已花的额度。
3. **用量会自己动。** 有用户报告在没有任何操作的情况下，用量隔夜从 30% 跳到 67%。社区猜测与动态公平使用机制有关，xAI 没有确认过原因。

额度用完不会封号：付费功能暂停，等重置日恢复，免费的聊天和语音照常可用。重置时间在 设置 > Usage 里查，按个人周期走，不是全员同一天重置。池子见底还可以从 $5 起购买额外用量，但有用户反馈充值后生成功能依然被锁，额外用量只对 API 和 Build 生效——已经到顶的情况下，别假设充值一定能解锁。

翻译成人话：聊天为主、每周几张图几条视频的轻度混合使用，基本感觉不到限额存在；以视频生成为主的人，会觉得 $30 买到的量远比想象中少，不如直接用视频专用工具。

## Plus 和 Heavy：什么人才需要考虑

从 $30 跳到 $100（Plus），买的不是不同的助手，是更大的量：1080p 视频、各功能更高额度、高峰期优先、新功能早享。判断方法很简单，你有没有真的把 $30 档的周池顶到过 100%？没有的话，这 $70 先留着。

Heavy（$300/月）值得单独算一笔账。它的核心模型和便宜档没有本质区别，多出来的 $270 买的是吞吐量：最高额度、最强推理模式、最多 16 个智能体并行拆解一个问题，外加捆绑的 X Premium+ 和专家支持。16 智能体模式是真实能力，更便宜的档位都没有，但它只对“面状问题”有效——大规模资料扫描、宽口径方案对比。如果你每周最难的活是改一个具体的 bug，十六个 agent 是高射炮打蚊子，$30 的 Grok Build 才是对的工具。

还有一点要泼冷水：即便在 Heavy 档，也有用户反馈重度图像视频工作一天烧掉一周的量。别把它当无限额度。
